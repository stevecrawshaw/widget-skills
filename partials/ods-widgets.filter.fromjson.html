fromjson
filter in module ods-widgets

Usage

In HTML Template Binding

{{ fromjson_expression | fromjson }}

In JavaScript

$filter('fromjson')(A)

Parameters

ParamTypeDetails
Astring

string value containing a stringified JSON object

Returns

json

The resulting, parsed, Json object

Example

value = '{\"key\":\"value\"}'

value|fromjson
{
  "key": "value"
}
