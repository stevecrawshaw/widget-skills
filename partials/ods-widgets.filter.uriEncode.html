uriEncode
filter in module ods-widgets

Description

This filter can be used to prepare a string to be used when building a link. It's important to understand that this filter encodes a string but ignores protocol prefix ('http://') and domain name. This filter uses the 'encodeURI' JavaScript function under the hood.

Usage

In HTML Template Binding

{{ uriEncode_expression | uriEncode }}

In JavaScript

$filter('uriEncode')(A)

Parameters

ParamTypeDetails
Astring

string.

Returns

string

A URL encoded value (but ignores protocol prefix ('http://') and domain name).

Example

value = 'https://website.com?x=шеллы'

value|uriEncode

https://website.com?x=%D1%88%D0%B5%D0%BB%D0%BB%D1%8B
